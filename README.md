# StayHealthy

StayHealthy is a patient-friendly healthcare web application designed to improve access to medical services, especially for remote and underserved communities.

## Features

- Responsive navigation
- Patient registration and login
- Doctor search
- Appointment booking
- Notifications
- Profile editing
- Reviews
- Appointment cancellation

## Setup

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Environment Variables

Create a `.env` file and configure your API base URL:

```env
VITE_API_BASE_URL=http://localhost:3000
```
